Regardless of the mocking library used, the typical way to mock `HttpClient` in .NET is not to mock `HttpClient` itself, but to mock its underlying `HttpMessageHandler`, which is what actually makes the HTTP calls.

While any mocking library should be able to mock `HttpMessageHandler` without issues, this site recommends the use of the [RichardSzalay.MockHttp](https://github.com/richardszalay/mockhttp) package. This package accomplishes the same thing as creating a mock for `HttpMessageHandler` yourself, but with a cleaner API and with other useful methods.

Regardless, this page will show how to do it with common mocking libraries, as well.
